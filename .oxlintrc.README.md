# Why these rules are off

`.oxlintrc.json` cannot carry comments — oxlint rejects unknown keys — so the
reasoning lives here. Each entry is a rule that fires on a pattern this codebase
uses deliberately. Anything not listed is on.

## Off everywhere

**`unicorn/prefer-add-event-listener`** — IndexedDB and Worker are `on<event>`
APIs by design. An `IDBRequest` is single-use, so "a previously registered
handler" cannot exist, and `workerRpc`'s `cleanup()` sets `onmessage = null` to
detach on abort. `addEventListener` would turn that one line into bookkeeping of
handler references, with a leak for every reference missed.

**`unicorn/require-post-message-target-origin`** — `targetOrigin` is a parameter
of `window.postMessage`. `Worker.postMessage` has no such parameter; the rule is
matching on the method name.

published API in the private SDK. A namespace of static
methods is the shape consumers already import; splitting it into loose functions
is a breaking change in exchange for a style preference.

**`no-underscore-dangle`** — a leading `_` marks a private field. That is the
convention throughout `SubstrateClient` and the vault stores.

**`unicorn/consistent-function-scoping`** — hoisting a small helper out of the
closure it reads from trades a clear local for a wider scope and a longer
parameter list.

## Off in `tests/` only

**`unicorn/no-array-sort`** and **`no-array-reverse`** — `toSorted()` is the
right default and `src/` uses it. In a test, `expect(Object.keys(x).sort())`
sorts an array built one expression earlier: there is nothing outliving the
assertion to mutate.

**`no-shadow`** — these suites define a `note` / `storage` / `pkm` fixture at
file scope and a narrower one inside a `describe`. The inner name is the one
being read, and renaming it to `note2` would make the tests harder to follow,
not safer.

**`no-unsafe-optional-chaining`** — `expect(result?.args['x'])` after asserting
`result` is not null. The throw the rule warns about is the test failing, which
is what it is there for.

**`no-useless-concat`** and **`unicorn/no-new-array`** — string and array
literals written for legibility in fixtures (`'0x' + '00'.repeat(32)`).
